```bash
git clone https://github.com/YOUR_USERNAME/plums.git
cd plums
go run .
```

## Keybindings

| Key | Action |
|---|---|
| `Tab` | Switch layout |
| `Shift + Enter` | Send message |
| `Ctrl + S` | Submit input |
| `Ctrl + C` | Quit |
| `Ctrl + A` | Select all |
| `Ctrl + K` | Delete current line |
| `Alt + ← / →` | Jump word |
| `Shift + Arrows` | Select text |
