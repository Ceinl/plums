Plums

Current Status

  • Not ready for beta deploy yet.
  • Close enough for internal alpha usage, but beta should wait until the core logic blockers below are fixed and verified in a clean worktree.
  • The current branch is main.
  • go test ./..., go build ./..., and go test -race ./... all pass locally.
  • internal/harness is experimental and outside beta scope.

Completed Since Last Roadmap

  • Closed keyboard input channels are handled in main.go; the main loop cancels active streams and exits instead of spinning.
  • Terminal startup now returns clean errors, including ErrNotTerminal, instead of panicking.
  • Resize events refresh terminal size and re-render the UI.
  • Quit paths cancel active streams and exit cleanly.
  • Opencode startup failure is surfaced as a system message, and early opencode serve exits include stderr.
  • Model switching is implemented through the command palette using the opencode provider API.
  • Plan/build mode is sent to opencode as the message agent.
  • The opencode server URL can be configured with [opencode].opencode_server_url in .agents/plums/config/config.toml.
  • Local custom opencode URLs now auto-start opencode serve on the configured hostname and port; non-local URLs are treated as attach-only.
  • Tests no longer depend on ignored docs/config fixtures.
  • internal/components/chatlog_test.go is tracked.
  • Generated binaries are ignored with /bin/ and /plums, and no generated binary paths are tracked.
  • Visible built-in palette commands now map to implemented behavior: model switching, new session, mode switching, output percentage, and session list.
  • Slash commands exist for /clear, /command, /new, and /sessions.
  • Tests cover non-TTY terminal startup, resize fallback, stdin EOF input handling, model/mode message payloads, startup exit reporting, palette search, and model selection.
  • Backend provider selection via config and -provider flag.
  • Runtime backend switching through the command palette.
  • Codex backend over codex app-server JSON-RPC stdio.
  • Tool call streaming and rendering in the chat log.
  • Structural refactor into cmd/internal/core/ui layout.
  • CI workflow added for tests, vet, and builds.
  • --version flag with metadata from build info and ldflags.
  • Mouse selection support for output and editor text.
  • Cmd+C / Cmd+Z / Cmd+V clipboard and undo support.
  • Thinking visibility toggle (full / title / hidden).
  • Git diff tab in the info view.

Beta Blockers

  • All agent system prompts are hard-coded to "TODO" in internal/core/harness/Agent.go. The LLM receives no actual behavioral instructions for any mode.
  • internal/core/registry.go is explicitly temporary — it contains fake outputs for agent listing, capabilities, and descriptions while the real core package is being built.
  • Codex ReplyQuestion is unimplemented — question/answer flows silently fail on the Codex backend.
  • The README is not beta-ready. It only documents a small config section and does not cover install, prerequisites, keybindings, first run, troubleshooting, or known limitations.
  • internal/app/keyboard.go has a gofmt indentation issue (under-indented case at Ctrl+C).

Public Launch Gate

  • Fresh install works from documented instructions.
  • CI is green for the release candidate.
  • Supported terminal matrix has been manually verified.

  • Release notes include known limitations and upgrade expectations.
