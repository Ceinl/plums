Plums Structural Refactor Plan

Goal: De-spaghetti the codebase into clean, abstracted packages with zero behavior changes. Everything that is hard-coded becomes a configurable default.

Current State Diagnosis

Critical issues found:
  • cmd/plums/main.go is 776 lines and still references the deleted internal/ai package.
  • keyhandling.go and clipboard.go are stranded in package main at project root.
  • internal/app/*.go files exist but are completely empty.
  • internal/ui/tui/app/*.go imports non-existent packages (internal/components, internal/layout, internal/screen) because files were moved but imports were not updated.
  • go:embed targets in cmd/plums/main.go are broken because embed paths are relative to the source file's directory.
  • internal/core/provider/opencode/opencode_test.go has a corrupted package name (opencodeopencodeopencode).

Step 6 — Build api/api.go wiring layer

  • Define type Config struct { ... } with every previously hard-coded value as a field with a sensible default.
  • Fields include:
    • OpencodeServerURL (default: http://127.0.0.1:4096)
    • GlobalConfigDir (default: ~/.config/plums/config)
    • LocalConfigDir (default: ./.agents/plums/config)
    • ClipboardCommand (default: pbcopy)
    • SpinnerInterval (default: 80ms)
    • HealthTimeout, QuestionReplyTimeout, RecentModelTimeout, etc.
    • DefaultLayoutType, DefaultMode, DefaultOutputPercent
  • Provide DefaultConfig() *Config.
  • Implement func Run(cfg *Config) error which:
    1. Loads render & command configs.
    2. Initializes terminal + keyboard listener.
    3. Creates the opencode backend via adapter.
    4. Creates core.AgentRegistry.
    5. Builds an app.Deps struct holding all wired dependencies.
    6. Calls app.Run(ctx, deps).

Step 8 — Make everything configurable (defaults + overrides)

  • All timeouts move from literals to api.Config fields.
  • Clipboard command becomes a field in Config (default pbcopy, overridable).
  • Config paths become fields (default global/local dirs).
  • App version remains a build-time ldflag but has a constant fallback.
  • Spinner ticker interval configurable (default 80ms).

Step 9 — Rewrite cmd/plums/main.go to minimal entry point

package main

import (
    "flag"
    "fmt"
    "os"
    "github.com/Ceinl/plums/api"
)

func main() {
    cfg := api.DefaultConfig()
    // define flags that override cfg fields
    flag.StringVar(&cfg.OpencodeServerURL, "server-url", cfg.OpencodeServerURL, "opencode server URL")
    // ... other flags
    flag.Parse()

    if err := api.Run(cfg); err != nil {
        fmt.Fprintf(os.Stderr, "plums: %v\n", err)
        os.Exit(1)
    }
}

Risk Mitigation

  • Behavior preservation: Every function body is copied verbatim; only package boundaries and import paths change.
  • Interface safety: The adapter.Backend interface is derived directly from the existing opencode client public methods, so it is 100% compatible.
  • Core stubs: Fake outputs in core/ use the exact signatures planned for the real implementation. When you replace them later, only the function bodies change.
  • Test coverage: All existing tests are migrated and import paths corrected before the final build.
